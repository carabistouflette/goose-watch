# Initial local records

Both records measure clean commit `8d3cda6` with all source hashes and measured
binary hashes retained. They include five rounds for each of three workload
sizes; the one C decoder timing per round is repeated in that round's three
workload rows, not three independent decoder measurements.

These are unisolated local Linux x86-64/glibc measurements with the recorded
compiler/toolchain. Every sample is retained. No cross-language comparison,
production throughput claim, latency percentile or sustained-load qualification
is made. See ../README.md for exact methodology and limits.
